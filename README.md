# SmartVibe 交易陪练

**真正需要训练的，不只是下单动作，而是每次决定背后的依据、风险和执行。**

普通模拟盘会告诉你赚了还是亏了，却很少继续追问：为什么在这里进场？仓位和愿意承担的亏损一致吗？这次遵守了计划，还是碰巧得到了一个好结果？

交易陪练是一个由数字分身、真实行情模拟练习和私教反馈组成的产品。它不替你预测行情，不给买卖信号，也不连接自动实盘交易。它希望做的是：让你先作决定，再帮助你看清自己的判断和执行，最后把问题变成下一次可以真正练习的任务。

> 当前状态：三阶段核心体验已在 Windows x64 完成产品验收，16 个测试文件、80 项测试通过。当前为公开预发布版本；macOS 安装入口和自动检查已经具备，但真实 Mac 设备上的完整安装、登录、授权、模型回合与重启恢复仍需验收。

## 它解决什么问题？

模拟资金可以反复重来，但交易习惯往往也会跟着反复重来。

- 赚了一笔，不等于这次决定正确；
- 亏了一笔，也不等于这次执行错误；
- 写了止损，不等于仓位真的符合风险预算；
- 练了很多次，不等于能够说清自己究竟改善了什么。

交易陪练不把盈亏当成唯一答案。它把用户的理由、仓位、止损、风险预算、模拟结果、复盘补充和下一次约定放在同一条可追溯的练习链里。

**核心体验可以概括成一句话：先认识你，再让你看见自己，最后陪你一轮一轮地练。**

## 三阶段体验

### 第一阶段：建立分身

先完成 8 道交易情境题，再填写自己的交易情况、困惑或目标。也可以选择上传从交易所导出的历史交易 CSV，为私教提供更多可以核对的行为证据。

私教会据此形成初始分身，并明确区分用户自述、已经看到的记录和仍需确认的问题。建档不是一次定型：后续交流、模拟决定和用户纠正都会继续保存，在相关场景中帮助私教理解你，但不会用一次表现把你永久定义成某种交易性格。

### 第二阶段：分身演示

选择一段真实的币安历史行情，从旁观察数字分身会怎样行动。

你会看到 K 线逐根展开，以及分身的开仓、加仓、退出或强平位置。分身只根据你的画像、相关记忆和播放开始前已经收盘的 K 线形成一次策略；播放过程由本地引擎执行，不会逐根调用模型，也不会提前读取未来行情。

演示支持：

- 任意有效币安交易对；
- 现货与 U 本位合约；
- 5 分钟、15 分钟、1 小时和 4 小时周期；
- 做多与做空、1—125 倍合约杠杆；
- 全仓与逐仓教学模拟；
- 自定义历史时间、演示根数、虚拟本金和投入比例；
- 可选填写记忆中的开仓价、加仓价和数量。

演示结束后，私教会和你讨论：这次分身的哪些反应像你，哪些不像？你的回答和纠正会保存下来，供之后相关分析参考。

> 合约强平采用教学用简化计算，没有复刻交易所全部维持保证金分档、资金费率和撮合细节，不能当作真实强平价格。

### 第三阶段：自主练习

自主练习是交易陪练的核心。它由当前练习任务、模拟交易、交易复盘、专项练习和阶段总结组成。

#### 1. 带着一项明确任务开始

首次进入时，先完成一笔模拟交易和平仓复盘。私教会结合这次表现提出第一项具体练习任务。

之后每轮围绕一项已确认任务进行。用户可以开始新任务，也可以继续当前练习再巩固一次。切换任务只会开启新的统计区间，不会覆盖过去的交易、对话和练习记录。

#### 2. 在当前币安行情中模拟交易

自主练习使用固定 **100,000 USDT** 初始练习本金，余额会随模拟盈亏和手续费变化，不支持自定义、迁移或重置本金。

当前支持：

- 任意有效币安交易对；
- 5 分钟、15 分钟、1 小时、4 小时和日线；
- 现货做多或观望；
- U 本位合约做多、做空和 1—125 倍杠杆；
- 市价单、限价单；
- 按资金比例或具体数量开仓；
- 止损、止盈、交易理由和风险预算。

当前 K 线通过币安 WebSocket 实时更新，完整行情和指标会定时同步。图表提供布林带、MACD 和 RSI，并显示当前任务中的开仓和平仓位置。

提交订单前，程序先计算资金占用、计划止损金额和风险预算关系。用户点击“请私教帮我检查计划”后，私教再结合当前盘面、订单设置、已确认任务和相关长期记录给出提醒。私教不会替用户决定方向；即使用户坚持原计划，也可以在理解风险后继续提交。

#### 3. 平仓后认真复盘

平仓后，用户可以请私教生成本次交易复盘。复盘不仅解释盈亏，还会对照交易理由、计划止损、风险预算和执行过程，指出做得清楚的地方以及下一次最值得改善的问题。

用户可以回答私教的追问，补充当时真实的想法。较早复盘、用户补充和更新后的复盘都会按顺序保留，不会只剩最后一份结果。

#### 4. 用专项练习巩固问题

专项练习围绕当前任务创建一段固定的真实历史行情，而不是另起一套无关训练。

提交前，浏览器只会取得决策点以前的 80 根 K 线，后续 12 根已收盘 K 线保持隐藏。用户需要先填写方向、训练本金、止损、风险预算，以及自己观察到的盘面依据和失效条件。

提交后，原决定会被锁定，后续 12 根 K 线才会揭晓。程序给出执行检查，私教只读取这次专项练习关联的决定、检查和决策前盘面，不会拿其他练习冒充本次证据，也不会单纯用事后涨跌判断决定好坏。

#### 5. 看见这一轮到底有没有变化

阶段进展会把当前任务开始后的模拟交易、已提交专项练习和用户补充交流串起来，帮助用户查看：

- 专项练习是否围绕当前任务；
- 决策依据是否写清；
- 是否设置了止损计划；
- 计划亏损是否符合风险预算；
- 相似场景中是否保持执行；
- 不同场景中能否迁移同一项约定。

系统会保留样本范围、第一次状态、最近一次状态和对应记录。少于两次有效样本时只提示样本不足，不会因为一次结果就宣布用户已经稳定改善。分身演示、未提交专项练习和真实账户成交不会被混入自主练习成绩。

最后，用户可以请私教总结这一轮，并自行决定开始下一项任务，还是继续当前练习再巩固一次。

## 交易陪练有什么不同？

### 用户先决定，私教再反馈

分身演示和专项练习都会控制未来信息。用户不能先看到答案再解释自己的选择，私教也不会替用户作出交易决定。

### 程序算账，私教理解

资金、手续费、盈亏、止损距离、指标、模拟撮合和阶段样本由程序计算；私教负责理解证据、解释概念、提出追问和组织下一次练习。模型不能修改账本，也不能编造计算结果。

### 有记忆，但不假装什么都记得

建档、模拟订单、专项训练和完整对话保存在本地。每次私教分析会按交易主题读取相关历史、近期自述和最新纠正，但这不是无限上下文，也不承诺所有旧内容每次都会进入模型。

### 失败时说真话

行情、授权、网络、模型或额度不可用时，页面会显示真实错误。已经填写的交易草稿和已经保存的训练记录不会因此被伪造或清空，本地程序检查也不会冒充私教已经完成点评。

### 进步要有证据

交易陪练不会因为一次盈利就宣布方法正确，也不会因为一个旧问题暂时没有出现就宣布能力已经提高。变化必须能够回到具体交易、训练或对话记录中核对。

## 和普通模拟盘的区别

| | 普通模拟盘 | 交易陪练 |
| :--- | :--- | :--- |
| 练习重点 | 主要关注下单和盈亏 | 同时关注依据、风险、执行和复盘 |
| 反馈方式 | 由用户自己解释结果 | 用户主动请求私教检查、追问和总结 |
| 训练连续性 | 每笔交易容易彼此孤立 | 问题会转化为下一轮可检查任务 |
| 进步判断 | 容易依赖主观感受 | 通过样本范围和可追溯记录谨慎判断 |
| 数据位置 | 取决于具体平台 | 训练记录默认保存在用户本机项目中 |

## 当前交易范围

自主练习当前采用“一次计划、一笔待成交或持仓、一笔完整平仓”的基础链路。以下能力属于后续进阶训练方向，**当前尚未支持**：

- 加仓、减仓和部分平仓；
- 持仓期间修改止损或止盈；
- 自主练习中的全仓/逐仓选择；
- 多仓位、多币种对冲和完整交易所持仓生命周期；
- 关闭网页后的持续撮合与后台盯盘。

第二阶段分身演示已经支持全仓、逐仓和加仓情境，但那是历史行情上的教学演示，不能等同于自主练习已经支持这些交易动作。

## 安装与使用

### 运行条件

- Windows x64：完整核心流程已经验收。
- macOS Apple Silicon / Intel：已经提供安装与启动入口，真实设备完整流程仍待发布前验收。
- Linux、Windows ARM64 和其他 Agent 客户端：当前不在支持范围。
- 完整私教体验需要联网、可用的 Codex 账号和模型额度。
- 币安官方授权用于相应的 MCP 和账户只读能力；部分行情可以明确回退到币安公开接口。公开行情可用不代表账户授权成功。

### 首次安装

1. 下载完整项目并解压到自己有写入权限的文件夹。不要只下载技能文件，也不要直接在压缩包里运行。
2. Windows 双击 `首次安装.cmd`；macOS 打开 `首次安装.command`。
3. 安装器会下载并校验项目内 Node.js 24.13.0，安装锁定依赖和 Codex CLI 0.153.4，再构建核心程序与网页。无需预装或修改系统 Node.js。
4. 安装完成后，在连接页由用户本人登录 Codex，并在币安官方页面选择授权。只选择行情或账户只读权限，不要开放交易、划转或提现权限。
5. 普通 Codex 登录失败时，再使用页面折叠区域中的设备代码备用方式。只输入自己刚刚在本机主动生成的代码，不使用他人发送的设备代码。

### 日常启动

- Windows：双击 `启动交易陪练.cmd`。
- macOS：打开 `启动交易陪练.command`。
- 网页地址：`http://localhost:3001/coach`。
- 请保留启动窗口。结束使用时回到该窗口按回车，等待服务正常停止。

不要从 IDE、Codex 任务或其他受限沙箱代为启动正式服务。受限环境可能无法读取系统根证书或登录配置，从而把正常安装误判成 Codex、币安或模型连接失败。

连接异常时可以运行 `连接检查.cmd` 或 `连接检查.command`，也可以进入网页的“连接设置与隐私说明”。连接检查成功只代表相应连接状态正常，不等于完整交易陪练体验已经通过。

## 数据与隐私

- 档案、模拟账本、行情快照、训练决定和对话默认保存在当前项目的 `data` 目录。移动或备份项目时请一起保留该目录。
- 独立 Codex 登录与连接配置由 Codex 管理并保存在 `.runtime/codex-home`；应用不会读取、复制或展示用户凭证。
- 点击私教功能时，完成当前分析所需的行情、模拟决定、相关记忆和用户补充会发送到用户已登录的 Codex 云端模型，因此产品不是完全离线。
- 不要在聊天、理由或目标中填写密码、API Key、助记词或无关敏感信息。
- 币安授权由用户在官方页面自行确认，应用不会代替用户同意权限。
- 真实账户事实、模拟练习和分身演示会分开保存和表述。Agentic 子账户没有成交不代表主账户没有成交。
- 服务只监听 `127.0.0.1:3001`，项目面向本机单用户运行，不应直接暴露到公网。

开发环境需要 Node.js `>=24.13.0 <25`：

```bash
npm ci
npm --prefix web ci
npm test
npm run test:runtime
npm run build
npm --prefix web run build
```

当前完整回归为 16 个测试文件、80 项测试通过，覆盖建档隔离、分身演示未来行情边界、模拟资金与订单、现货/合约行情路由、长期记忆、专项练习信息隔离、阶段进展、Codex 连接恢复和跨平台运行逻辑。

自动检查会在 Windows 和 macOS 环境执行依赖安装、测试、核心构建和网页构建，并检查 macOS 脚本语法与可执行位。自动检查不能代替真实设备上的登录、OAuth 和完整产品体验验收。

## Agent Skill 与可选 MCP

完整体验入口是网页，不要求额外安装本地 MCP。

- `agent/smartvibe-trading-doppelganger/SKILL.md`：帮助兼容 Agent 引导安装、启动和网页使用。
- `agent/mcp.cursor.example.json`：早期本地 MCP 的可选配置模板，使用前必须替换为自己的项目绝对路径。
- 早期 MCP 只保留建档、样本和规则类工具，不能替代网页中的私教、模拟账本、专项练习和阶段总结。

## 风险声明

交易陪练仅用于交易教育、模拟练习和行为复盘：

- 不连接自动实盘下单；
- 不提供确定的买卖信号；
- 不承诺收益、胜率或风险降低；
- 模拟成交、手续费、止损触发和强平结果不等同于交易所真实执行；
- 任何真实交易决定与损失均由用户自行承担。

交易陪练不能保证每笔交易都会得到私教点评，但它希望让每一笔值得复盘的模拟交易，都不只剩下一个盈亏数字。
