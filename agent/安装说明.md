# 安装说明

请从完整项目根目录的 [README.md](../README.md) 开始，按「首次安装 → 自己登录与授权 → 启动网页 → 八题建档与练习」操作。

Codex默认采用普通OAuth登录。设备代码只作为普通登录失败后的折叠备用入口，页面必须提前说明OpenAI会显示防钓鱼提醒，并明确只有用户刚刚在本机主动生成的代码才可输入。币安仍使用其官方OAuth页面。

启动必须由用户在操作系统桌面直接打开 `.cmd` 或 `.command`，不要由IDE、Codex任务或其他沙箱代为运行。沙箱启动的网页可能返回200，但其后台子进程可能无权读取系统根证书，不能据此验收登录和模型连接。

安装入口采用项目内Node.js 24.13.0与Codex CLI 0.153.4。Windows x64使用.cmd入口；macOS Apple Silicon或Intel使用.command入口，两者进入共享的Node运行管理程序。macOS真实设备的登录、币安OAuth、重启恢复与完整陪练仍须在发布前完成验收。技能包帮助使用网页；早期本地MCP不承担完整私教训练流程。

旧 Cursor 优先安装步骤、三个冷启动情景、复制开发者路径和样本兜底说明已停止作为安装依据。完整验收状态见 [发布验收.md](发布验收.md)。
